# MathCanvas

在 iPad 上用 Apple Pencil 手写数学步骤，点击发送后自动传到 Mac 本地服务，并写入系统剪贴板，直接 `Cmd+V` 粘贴使用。

## 功能

- iPad 全屏手写（PencilKit）
- 无边记风格画布（可缩放/平移）
- 一键发送图片到 Mac（局域网 HTTP）
- Mac 自动写剪贴板，方便粘贴到 AI 的聊天窗口
- App 内可修改服务地址 + **首次使用自动弹出配置 + 「测试连接」按钮**，给朋友用时几乎零门槛
- Mac 服务启动时自动识别真实局域网 IP，并警告不要使用 VPN 虚拟地址（198.18.x）

## 快速开始（新用户 3 分钟）

### 1) 在 Mac 上启动接收服务

在项目目录运行：

```bash
python3 mac_server/clipboard_server.py
```

或直接双击：

`mac_server/start_server.command`

服务启动后，终端会输出类似下面这样：

```
推荐 iPad 地址: http://192.168.1.181:8765/upload
其他可用地址（iPad 与 Mac 须在同一网段时选对应 IP）：
  http://192.168.2.1:8765/upload
健康检查: http://192.168.1.181:8765/health
提示: 若看到 198.18.x，那是 VPN/代理虚拟网卡，iPad 无法访问。
```

**关键**：只复制「推荐 iPad 地址」或下面列出的真实局域网地址，**不要用 198.18.x.x** 的地址！

### 2) iPad 端第一次配置（会自动引导）

- 第一次打开 App 时，会**自动弹出「首次设置」窗口**。
- 把 Mac 终端打印的完整地址（包含 `http://` 和 `/upload`）粘贴进去。
- 点击「测试连接」，直到下方出现 **绿色「连接成功 ✓」**。
- 点击右上角「保存」。

之后任何时候想改地址，点右下角「服务」按钮即可手动打开设置页。

设置页里还提供了「使用示例格式」和实时「测试连接」功能，强烈建议每次改完 IP 都先测试一下。

### 3) 开始手写并发送

1. iPad 和 Mac 必须连**同一个 Wi-Fi**（IP 网段也要一致，例如都是 192.168.1.x）。
2. 在 iPad 全屏画布上用 Apple Pencil 手写数学步骤。
3. 点击右下角「发送」。
4. Mac 收到图片后会自动写入系统剪贴板。
5. 在 Mac 任意输入框按 `Cmd + V` 直接粘贴使用。

右下角「服务」按钮会根据是否已配置显示不同颜色（未配置时为橙色，提醒你先去设置）。未配置时点击「发送」也会自动弹出设置页。

## 常见问题

### Mac 服务相关

- **Address already in use**
  - 端口 8765 被占用；先在终端执行 `kill $(lsof -tiTCP:8765 -sTCP:LISTEN)` 再重启服务。
- **终端推荐地址是 198.18.x.x**
  - 这是 VPN / 代理（Clash、Surge 等）创建的虚拟网卡地址，iPad 在真实 Wi-Fi 上完全访问不到。
  - 服务启动时现在会**特别提示**并列出所有可用的真实局域网地址（192.168.x / 10.x / 172.x），请使用这些。
- **Mac 防火墙拦截**
  - 系统设置 → 网络 → 防火墙 → 允许 Python / Terminal 接受传入连接。
  - 或者临时关闭防火墙测试。

### iPad 配置与发送

- **第一次打开 App 没有自动弹出设置页**
  - 说明之前已经保存过地址（可能是上一个用户留下的）。直接点右下角「服务」手动打开设置即可。
- **测试连接 / 发送一直失败**
  - iPad 和 Mac 必须在**同一个 Wi-Fi**，且 IP 属于同一网段（例如 iPad 是 192.168.1.50，Mac 就应该填 192.168.1.181）。
  - 用「测试连接」按钮验证，不要直接点发送猜。
  - 第一次使用时 iPad 会弹出「MathCanvas 需要访问局域网」权限，必须点「允许」。
- **填了地址但点保存后还是发不出去**
  - 先确认「当前地址」那一行显示的是你刚刚保存的地址（不是「尚未设置」）。
  - 再用「测试连接」确认绿勾。
- **iPad 提示“无法连接”或超时**
  - 检查 Mac 服务是否还在运行（终端窗口不能关）。
  - 不要使用任何 198.18.x 地址。
  - 尝试把 iPad 和 Mac 都重启一下 Wi-Fi 连接。

### 剪贴板相关

- **能收到文件但没进剪贴板**
  - 先看 Mac 服务终端的日志输出。
  - 重启服务试试。
  - 确认 macOS「系统设置 → 隐私与安全性 → 自动化」里允许了对应终端 / Python 控制剪贴板（如果有弹窗要点允许）。

### 其他

- **想给朋友用**
  - 让朋友也运行同样的 `python3 mac_server/clipboard_server.py`，然后把他们自己 Mac 打印的地址告诉他们。
  - iPad App 目前需要用 Xcode 自己编译安装（或通过 TestFlight 分发）。地址完全由对方自己配置。
- **多网卡 / 有线 + Wi-Fi + VPN 并存**
  - Mac 服务启动时会把所有“看起来像真实局域网”的地址都列出来，让 iPad 当前所在网络的设备选对应的 IP 填入即可。
